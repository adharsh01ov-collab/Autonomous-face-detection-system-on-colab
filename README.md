### Autonomous Face Detection & Storage System

The **Autonomous Face Detection & Storage System** is a computer vision-based project developed to automatically detect human faces from images, videos, and live webcam streams and store the detected face data for further analysis. The system focuses on reliable face detection and automated image processing rather than identifying or recognizing specific individuals. It was developed using **Python, OpenCV, MTCNN, PyTorch, NumPy, Pandas, PIL, and SQLite**, with Google Colab used as the primary development environment.

The core of the system uses **MTCNN (Multi-task Cascaded Convolutional Networks)** for detecting faces within input frames. MTCNN identifies the coordinates of detected faces and provides a confidence score for each detection. A configurable detection-confidence threshold is applied to filter weak detections and improve the reliability of the output. Once a face is detected, its bounding-box coordinates are extracted and the corresponding facial region is cropped from the original image.

The system is designed to work with multiple faces in a single frame. Each detected face is processed independently, allowing the application to identify and store multiple face regions from the same image or video frame. The detected regions can then be saved as individual image files, creating a collection of face crops that can be used for later analysis, dataset creation, or computer vision experiments.

A major feature of the project is its **automated storage and logging mechanism**. An SQLite database is used to maintain structured information about detected faces and their corresponding events. The database stores detection records along with timestamps, input sources, and paths to the saved face crops. This makes it possible to maintain a searchable history of face-detection events rather than simply displaying the detected faces temporarily.

The system supports **three input modes: uploaded images, video files, and live webcam streams**. For image processing, users can upload one or more images and the system automatically detects faces and displays the results with bounding boxes. For video processing, the system reads frames from a video file and processes selected frames at configurable intervals, reducing unnecessary computation. For live webcam operation, frames are periodically captured from the browser camera and passed through the detection pipeline automatically.

The detected faces are visually highlighted using bounding boxes, allowing users to clearly identify the regions detected by the model. The system also provides configurable parameters such as detection confidence thresholds and processing intervals, allowing the application to be adjusted according to different input conditions and performance requirements.

The project demonstrates practical implementation of **computer vision, deep-learning-based object detection, image preprocessing, automated data storage, video processing, and real-time webcam processing**. It also provides experience in integrating pretrained AI models with OpenCV and database technologies to create an end-to-end application.

Overall, the **Autonomous Face Detection & Storage System** demonstrates how AI-based face detection can be integrated with automated image capture and structured data management. The project can serve as a foundation for applications such as **attendance systems, visitor monitoring, face-detection datasets, smart camera systems, and other computer-vision applications**, while requiring appropriate privacy and consent practices when handling facial images.
